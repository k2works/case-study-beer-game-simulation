### ゴール

進行役が観察用の招待を発行・失効でき、観察者は招待で参加して、読み取り専用で観察する。観察の画面は、現在週・ステップ・完了状況と、逆算できないチーム合計だけを示し、役割別の値と将来の需要は返さない。

### 確認したい仮説

1. **情報が漏れないか**（[リリース計画](./release_plan.md)の仮説）。観察者の資格で、役割別の状況・進行役のコンソール・振り返り（終了前）・すべての変更の操作が拒否され、観察の応答に役割別の値と需要が含まれないか。
2. 開示の判定（`DisclosurePolicy`）を、純粋関数として、寄与者の数と公開範囲だけから決められるか。

### 対象の受入条件（原文）

| ID      | Given / When / Then（原文）                                                                      |
| :------ | :----------------------------------------------------------------------------------------------- |
| AC1.3.1 | 進行役が観察用の招待を求めると、参加コードと別の招待が発行される                                 |
| AC1.3.2 | 進行役以外が求めると、発行しない                                                                 |
| AC1.3.3 | 観察用の招待で参加した人は、役割を持たず、状態を変更できない                                     |
| AC1.3.4 | 進行役が招待を失効させると、その招待での新しい参加はできなくなる                                 |
| AC4.1.1 | プレイ中に観察画面を開くと、現在週・ステップ・完了状況・在庫・受注残・注文のチーム合計を表示する |
| AC4.1.2 | 観察者が役割別の値や未来の需要を取得しようとすると、権限エラーとして、値を返さない               |
| AC4.1.3 | 集計の対象が 1 役割だけで、逆算により個別の値が漏れる状態では、合計を非表示にする                |
| AC4.1.4 | 観察用の招待で参加した観察者だけが、観察画面を開ける（招待の無い人は開けない）                   |
| AC4.1.5 | 観察者は、入力、確定、進行の操作をできない                                                       |

期待値の解釈:

- 「ステップ」は、当週の段階（入力中 / 確定待ち / 停止中 / 終了）と読む。
- 在庫・受注残のチーム合計は、**最後に確定した週**の 4 役割の合計（寄与は常に 4 役割）。注文のチーム合計は、**当週の入力済みの役割の合計**で、入力済みが 2 役割未満なら非表示（AC4.1.3 の「逆算できる状態」）。
- 公開範囲が「進行状況だけ」なら、合計を出さない。
- AC4.1.4 の「観察者だけ」は、観察の画面を開ける人を、**そのゲームの観察者と進行役**に限ると読む。[UI 設計](../../design/beer-game2/ui-design.md)の S07 は参加者も利用者に挙げるが、**参加者は自分の値を知っているため、2 役割の注文の合計から相手の値を逆算できる**。参加者には開かせない（UI 設計との差分として、終了報告に記録する）。

### 範囲外

観察者の人数の上限の運用、観察者の一覧の表示、終了後の観察者の振り返り（B3 の振り返りの開示に観察者を加える）は、この Bolt で扱う（下記の判断項目）。出力は B9。
