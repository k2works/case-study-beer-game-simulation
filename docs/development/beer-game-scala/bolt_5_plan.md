### ゴール

同一役割に複数の参加者を割り当て、意思決定の版（`If-Match`）で競合を検出する。競合した人には、最新の入力・保存者・保存の時刻を示し、同時の保存で更新を失わないことを並行のテストで確かめる。

### 確認したい仮説

1. 同時の保存で更新を失わないか（楽観的並行制御）。
2. 再試行は上限内で収まるか。
3. 表示名・保存者を、同じ役割の共同担当と進行役にだけ示し、他の役割へ漏らさずにできるか。

### 対象の受入条件

| 対象 | 内容 |
| :--- | :--- |
| AC1.2.4 | 同じ役割に複数人。各役割に 1 人以上で開始できる |
| AC2.1.4 | 共同担当は同じ状況・入力値・版を見る。保存者と共同担当の一覧は同じ役割にだけ |
| AC2.2.3 | 同じ版からの 2 回目の保存は競合し、最新の入力・保存者・時刻を示す |
| AC2.2.4 | 共同担当の一人が保存すると、別の共同担当が取得した状況も同じ値・版になる |
| NF-C8 | 保存回数の上限は共同担当で共有。競合で拒否した保存は数えない |
