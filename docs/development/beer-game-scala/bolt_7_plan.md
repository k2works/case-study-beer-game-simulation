### ゴール

確定方式（手動・自動）の設定と、4 役割の入力がそろったときの自動確定を実装する。確定は、最後の入力（参加者の保存・代理入力）・再開・方式の変更と同じ追記で行い、停止中は確定しない。手動の確定と競合しても、結果は一度だけ計上する。Release 0.2 の範囲。

### 確認したい仮説

1. 自動確定と手動確定の競合で、一度だけ確定されるか。
2. 自動確定の判定を、保存と同じ追記に置いて、停止・再開と矛盾しないか。

### 対象の受入条件

| 対象 | 内容 |
| :--- | :--- |
| AC1.1.6 | 確定方式の設定。既定は手動。不正な値は作成せず修正内容を示す |
| AC2.4.1 | 4 役割がそろうと、同じ追記で週が一度だけ確定される（代理入力を含む） |
| AC2.4.2 | 手動のゲームでは、そろっても確定されない |
| AC2.4.3 | 停止中は確定せず、再開で確定する |
| AC2.4.4 | 自動確定と手動確定が競合しても、一度だけ計上される |
| AC2.4.5 | 進行役はいつでも確定方式を変えられる。有効にした時点でそろっていれば確定。参加者は変えられない |
