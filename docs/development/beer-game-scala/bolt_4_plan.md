### ゴール

停止・再開・代理入力、参加者・進行役の復帰、資格の期限・失効・再発行、鍵の複数の版、試行の窓を実装し、**認可を冪等記録の照合より先に置く**（ADR-004）。開始後の役割の入れ替え（D3）も含める。

### 確認したい仮説

1. 資格の設計は、漏洩時に被害を止められるか（失効でブラウザセッションと復帰資格がともに使えなくなるか）。
2. 失効した資格が、以前に成功した要求を同じキーで再送しても 403 か。
3. 鍵のローテーション後も旧版の資格は期限まで使え、旧版を外すと使えなくなるか。
4. 接続元ごとの失敗の窓で、参加コードの総当たりを止められるか。

### 対象の受入条件

| 対象 | 内容 |
| :--- | :--- |
| AC3.1.1〜3.1.3 | 停止中の保存・確定の拒否、代理入力（停止中も可・週は確定しない）、再開 |
| AC3.2.1〜3.2.4 | 復帰資格・復帰コードでの復帰（参加者・進行役）。無効な資格は区別しない 403 |
| AC3.2.5 | 失効・再発行・期限切れ・鍵のローテーション・役割の入れ替え |
| NF-S11・NF-S19 | 参加コードの失敗の窓（既定 10 回・10 分。未計測の仮置き） |
| 保存回数の上限（NF-C8） | 1 役割・1 週あたり 9 回（代理入力を含む） |

### 範囲外（後続の Bolt）

共同担当・共同入力（B5）。観察者の資格（B9）。進行役自身の資格の失効・再発行。
