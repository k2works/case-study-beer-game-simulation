### ゴール

ゲームの終了後に、全役割の全週の結果（注文・在庫・受注残・出荷・費用）を、進行役と参加者が取得できるようにする。終了前は、進行役にも参加者にも開示しない。ブルウィップ効果が見えるよう、需要（小売店の受注）と全役割の時系列を同じ形で返す。

### 確認したい仮説

1. 役割別の週結果の行（B1 から保存している `WeekCommitted`）だけで、振り返りが単純に実現できるか（投影表なし）。
2. 終了前は開示せず、資格が無い場合は区別しない 403 にできるか。

### 対象の受入条件

| 対象 | 内容 |
| :--- | :--- |
| AC4.2.1 | 終了後、進行役・参加者が、他の役割を含む全役割の全週の結果を取得できる |
| AC4.2.2 | プレイ中は、進行役にも参加者にも開示しない（`game.not_ended`。409）。資格が無い人には 403 |
| AC4.2.3・4.2.4 | 指標・役割の切り替え、グラフと表（画面。`retrospective-ui.feature`。共有の Web で確認できる範囲） |
