## 計測の条件と限界

- **環境**: 手元（macOS の Docker Desktop）の実 PostgreSQL 18.6（Testcontainers）。接続プールは 8 本。**インプロセスの HTTP ルーター**を呼ぶ（ネットワーク・ブラウザ・SSE・複数タスクを含まない）。AWS（Fargate・RDS）の値ではない。
- **規模**: `BEERGAME_MEASURE=1` で全規模（15 ゲーム・75 並行・長いストリーム 1000/2000 件・50 週）。**3 回実行**した（標本は少なく、p95 の下側は参考値）。
- **コンテナ**: 1 CPU・2 GiB（Terraform の既定値）。同じ条件で Kotlin 版のイメージも測った（比較は報告書）。
