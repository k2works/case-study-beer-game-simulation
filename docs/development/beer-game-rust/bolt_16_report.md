## 実施中に見つけて是正した本番の欠陥

1. **Cookie に `Secure` が付いていなかった（NF-S2。重大）**: `main.rs` が `secure_cookies` を常に `false` で渡していた。B15 までの検査では、検出できていなかった。**`ENVIRONMENT` が `local` 以外のとき付ける**ようにした（ステージング・本番で付く）。`local`・未設定では付けない（手元の HTTP のため）。
2. **リクエストの本文の上限が、axum の既定（2 MiB）だった（NF-P12 は 64 KB）**: 64 KB に制限した（413）。
3. **同じゲームの 4 人が同時に保存すると、再試行の上限超過の 503 が間欠的に出た（Release 0.2 の条件「4 人同時の保存で `RetryExhausted` が出ない」の違反。NF-C2）**: 追記の競合は、再試行のたびに他の書き手が 1 人成功するので、**上限を同時の書き手の数以上にすれば、上限超過は起きない**。上限を **3 → 6**（4 役割 + 進行役 + 共同担当）にし、「上限が書き手の数未満ならコンパイルが通らない」検査を置いた。是正後は、全規模の 3 回で **0/60**。

## 見つけたが是正していないもの（人の判断）

1. **同時の保存の p95 が、不安定**: 是正後も 793 / 1144 / 857 ms で、3 回中 1 回が NF-P1 の 1 秒を超えた。503 は出ないが、**同じゲームの 4 人の書き込みは、1 本のストリームで直列になる**ため、待ちが生じる。目標を緩める・設計を変える（書き込みの単位を分ける）・現状を許容する、のどれかは人が決める。
2. **Origin・Referer の検査（NF-S8）が未実装**: `SameSite=Strict` と、変更系のヘッダー（版・冪等キー）で緩和している。実装には、許可するオリジンの設定が要る。
3. **イベントの封筒の `correlation_id` が、リクエストの相関 ID でなく、イベントの ID**（NF-O2 の一部）。
4. **NFR の件数**: リリース計画は 86 件としていたが、実際の NF は **82 件**（C 9・O 13・P 20・R 18・S 22）。

## 未確認・簡略化（人の判断が要る項目）

1. **本番の値は、すべて未確認**: 計測は手元。Fargate・RDS（Multi-AZ）・CloudFront・ALB の値は無い。
2. **画面を介した性能（NF-P2 の実測、NF-P5）、観察・振り返り・保持状態の取得（NF-P8・P10）、自動確定・代理入力（NF-P14・P6 の一部）、100 ゲームの再構築、読み取りの負荷の下の出力、は未測定**（[nfr_results](./nfr_results.md)）。
3. **スクリーンリーダーの確認、axe-core の導入、Edge・実機の Safari は未実施**（人の確認）。
4. **NF-C1 の負荷（75 の SSE）での RSS は未測定**（SSE が未実装）。
5. **Docker の計測は macOS の仮想機の上**。Linux の RSS は取れたが、Fargate と違う。
6. **新規ファイル**: `app/tests/performance.rs`、`docs/development/beer-game-rust/nfr_results.md`・`release_readiness.md`。計測のスクリプト（`container-measure*.sh`）は、スクラッチパッドに置き、**リポジトリには置いていない**（再現の手順は、報告のとおり）。
7. **TDD の順序**: 設定（`secure_cookies`・`MAX_ATTEMPTS`）、本文の上限は、テストを先に書いて失敗を確かめた。**計測のテストは、アプリのコードを変えない測定で、失敗を先に確かめる対象ではない**。**計測の最初の版は、480 件を一斉に出す設計で「75 並行」を誤って測った**ため、順次の 75 並行と一斉（ストレス）に分けて直した。
8. **ソースの編集に `sed -i` を使った箇所**: `index.md` の 1 行の追加（ドキュメント。`sed -i` で 1 行を挿入した）。コードのソースでは使っていない。
9. **ワークツリーの片付け**: 計測の Docker のコンテナ・ネットワークは、スクリプトの終了時に削除した。**Docker イメージ `beer-game-rust:measure` と、過去のテスト用コンテナ（B12・B13 で記録）は残っている**（ユーザーの開発用 DB が混ざるため、掃除していない）。
