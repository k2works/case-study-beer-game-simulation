## B2 への申し送り

B2（規約検査・CI・テスト基盤）の計画で、次の承認と確認を求める。**B2 の結果が悪ければ（detekt・PMD と Kotlin 2.4 の互換、Kover、連鎖削除）、B3 以降を止める**（リリース計画）。

- **承認**: PMD の導入（14 ルール、fixture）、API の契約テストの道具の選定と導入（型の生成を含む。B1 では型を手書きした）、detekt の代替（JDK 25 で動く解析）の判断。
- **確認**: Kover の `test` と `integrationTest`・受け入れの合算、CI（GitHub Actions）での実行（`integrationTest` が必ず実行されること、`acceptanceTest` を `check` に組み込むか、受け入れの CI での所要）、`ForbiddenMethodCall` が `mutableListOf`（インライン関数）を検出しないことの PMD での補完。
- **実装**: 追記専用権限の否定テスト（V101 のロールと GRANT。H2 では守られない）、連鎖削除が `events` に DELETE 権限を持たないロールで動くことの Red、N-1 互換、フロントエンドの lint での握りつぶしの検出、`@Suppress`・ベースラインの機械検査、`.github/workflows/beer-game-kotlin.yml` の action の SHA 固定、Cucumber のタグの整合検査（`@US`・`@AC`）、生きたドキュメントの導線（上の A2）、`acceptanceTest` のリソースから `TAGS.md` の除外。
- **持ち越し（B1 から）**: 参加の応答の `gameId`（#1）、SSE と `LISTEN` 切断中の欠落の補完、冪等記録の掃除、投影の整合検査、DB ロールの分離（読み取り専用）、鍵の版の複数保持。
