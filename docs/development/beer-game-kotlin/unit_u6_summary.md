## 4. U6 が完了と言える範囲と言えない範囲

- **言える**: ローカルの PostgreSQL・インプロセスの Ktor の上で、主要な API の性能の実測がそろい、横断の受入条件のうち X-3・X-4 と、X-1・X-5 の自動の部分が満たされること。ヘルプと狭い画面の案内、キーボード・200% 拡大・コントラスト比の自動の検査が動くこと。3 つのブラウザエンジンで `@ui` を実行した結果（Firefox の 1 件を除き緑）。
- **言えない**: 「非機能の目標を満たす」こと（未達 5 件、未測定・未実施・未確認 11 件）。スクリーンリーダーでの利用、実機のブラウザ、実環境の性能、ブラウザの 75 ユーザーの負荷、研修中の SSE による即時の反映。**「リリース 1.0 の条件（NFR の全件が実施済み）」を、記録としては満たしたが、実測が目標を満たさない項目を含む。**
