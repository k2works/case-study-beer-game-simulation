## 6. U1 が「完了」と言える範囲と言えない範囲

### 機械的に確認できたこと（ローカルで再現できる事実）

- ローカルで `./gradlew build integrationTest acceptanceTest acceptanceTestH2 koverVerify --rerun-tasks`（JDK 25）が成功し、586 件（Kotlin 側）と `web` の 70 件が失敗 0。detekt（JDK 21）・PMD・ktlint は違反 0。
- 受入シナリオ（日本語 Gherkin、`@api` 27 件）が PostgreSQL 18 と H2 の両方で成功。`@ui` の 1 シナリオが成功。
- 追記専用権限の否定テスト、連鎖削除、契約テスト（変異を含む）が成功。
- コンテナがビルドでき、スモークテストが全項目成功（H2 の拒否、秘密無しの失敗、未実装モードの失敗を含む）。起動時間は最大 6.0 秒（ローカル）。
- Terraform の定義が `fmt -check`・`validate` に成功。デプロイ・ロールバックのワークフローが `workflow_dispatch` のみ（構文検証済み）。

### 言えること（条件つき）

- 「ウォーキングスケルトンの縦の経路は、**ローカルで機械的な検証を通った**」。ES + CQRS の 1 ゲーム、規約検査の基盤、契約テスト、コンテナの定義は、実装と実測の根拠がある。
- 「B2 で不安だった技術的な未知（detekt・PMD と Kotlin 2.4、連鎖削除と追記専用、Kover の合算）は、**ローカルでは解消または回避策がある**」。

### 言えないこと（人の確認・外部の確認が要る）

- **「U1 が承認された」「Release 0.1 の条件を満たした」**: ゲートはすべて未承認、B4 は未着手、domain の行 100%・`plan`・CI の実行は未達または未確認。
- **「CI で動く」**: GitHub Actions では一度も実行していない。ローカルと同じタスクを実行した事実があるだけ。
- **「デプロイできる」「ロールバックできる」「AWS で動く」**: ワークフローと Terraform は AWS で未実行、`plan` も未実行。IAM の突合も未実施。
- **「性能目標を満たす」**: 起動時間はローカルの値のみ、p95 は言えない。負荷試験は未実施（B15）。
- **「人が理解して承認したコード」**: コードの全行理解の承認は未実施。AI の自己申告の誤りが B1 で 1 件あった（`@Suppress` の「無い」の報告）。人の検証が入っていない分、見つかっていない誤りが残る可能性がある。
- **「設計と実装が一致している」**: インフラは 4 点で設計と異なり、人の判断待ち。設計書は `draft`。

## 9. 次への申し送り

### 次の Unit・Bolt の候補

リリース計画の順序は、B4（U4 の振り返りの核。Release 0.1）→ B5〜B8（U2・U3。Release 0.2）→ B9〜B15（Release 1.0）。**「U4 の振り返り」（B4）が次**。

着手前に、次を確認してほしい。

1. **優先度 A の #1〜#7**。特に、U1 のゲートを検証するか（#1）、B2 の判定（#2）、`plan` の受入条件（#4）、push して GitHub Actions の実行を確認するか（#5）。
2. **B4 の前提**: 参加の応答の `gameId`（#12。B4 は画面を含む）。契約テストの運用（仕様 → 契約テスト（Red）→ 実装 → 型の再生成 → 画面）。`@ui` の拡張（参加者の画面）。B4 の受入条件 AC4.2.1〜4.2.4 を、実装の前に人が Gherkin で検証する。
3. **B4 の計画**: 前の Bolt の申し送りを項目として取り込む（学び 7）。計画の作成後に `validating-design` を実施し、着手前の記録を残す。

5. 所要の再調整: 実績が 3 例（B1・B2・B3）で、いずれも人の検証時間を含まないため、リリース計画の所要（Release 0.1 は 2026-11-30、1.0 は 2027-01-06）は**変更しない**。人の検証を含めた実績を取ってから判断する。

### 以降のゲート密度の判断

リリース計画は、B1〜B3 を「密」、以降の Bolt を高リスクは密・他は標準とする。U1 では人のゲートが機能しておらず、**密度を下げる根拠が無い**。B4 は標準だが、U1 の判断（#1）が済むまでは、ステップごとに人の確認を入れることを勧める。
