    ウォーキングスケルトンのガイドツアー（生成）¶

    この文書は、コードの注釈とソースから生成した。手で編集しない（試験 LivingDocumentationSpec が、コードとの不一致で失敗する）。再生成: ./gradlew :domain:generateLivingDocs。

    最初の縦の切片（1 ゲーム・4 役割・1 週）を、操作の順に、画面からイベントと投影までたどる。 各層の場所は、コードの走査から導く。見つからなければ、ツアーが古いので、試験が失敗する。 API の経路は、仕様（contracts/openapi.yaml。基準の URL は /api/v1）の操作から読む。
