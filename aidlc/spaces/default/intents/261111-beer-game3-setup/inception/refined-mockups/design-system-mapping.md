# デザインシステムとの対応

画面部品は、既成のデザインシステムの考え方（余白、色、状態の表現の決まり）を土台に揃えます（Q1）。具体的な部品やライブラリは、技術スタックを選ぶ工程で決めます。ここでは、どのデザインシステムを選んでも守る決まりと、画面の部品との対応を定めます。

## 基本の決まり

### 余白の尺度

4px、8px、16px、24px、32px、48px の尺度だけを使う。余白を尺度の外の値にしない。

### 文字

- 画面の言語は日本語のみ（NFR11）。ページの言語を日本語と宣言する
- 本文は 16px 以上、行の高さは文字の大きさの 1.5 倍以上
- 見出しは階層を飛ばさない（h1 から順に）

### 色の役割

色は、意味ではなく役割で定め、具体的な値は技術スタックの工程で決める。どの値にしても、文字と背景のコントラストは 4.5:1 以上、枠や図形は 3:1 以上を満たす（NFR8）。

| 役割 | 使いどころ | 色以外の併用 |
| :--- | :--- | :--- |
| 主要 | 主な操作のボタン、現在のステップ | 太い枠、文字 |
| 成功 | 保存済み、入力済み | チェックの印と文字 |
| 注意 | 一時停止、仮の値、カスタム | 注意の印と文字 |
| 誤り | 入力の誤り、確定の失敗 | 誤りの印と文章 |
| 情報 | 案内、置き換わりの通知 | 情報の印と文字 |
| 中立 | 背景、区切り | なし |

状態は、色だけでなく、印と文字で必ず表す。

### フォーカス

すべての操作できる要素に、見えるフォーカスの枠（太さ 2px 以上、コントラスト 3:1 以上）を付ける。フォーカスの枠を消さない。

### 動き

動きは 300ms 以内。`prefers-reduced-motion` を尊重して、動きを止められるようにする。

## 画面部品との対応

| 画面の部品 | 使う画面 | デザインシステムの部品の種類 | 注意 |
| :--- | :--- | :--- | :--- |
| 主要ボタン、副次ボタン | 全画面 | ボタン | 1 つの区画に主要ボタンは 1 つ |
| 数値の入力欄 | S1、S3、S4 | テキスト入力（数値） | ラベルを常に表示 |
| 選択（単一） | S1、S2、S6 | ラジオ、セレクト | 矢印キーで移動 |
| 選択（スイッチ） | S1（公開範囲） | チェックボックス | |
| 表 | S2、S3（履歴）、S4、S6 | データ表 | 見出しと関連づける |
| 帯（一時停止、切断） | S3、S4、S5 | バナー | 色だけでなく文字 |
| 確認ダイアログ | S4 | ダイアログ | フォーカスを留める |
| ステップの表示 | S3 | ステッパー | 現在を `aria-current` |
| タブ・表示の切り替え | S6 | タブ、切り替え | 矢印キーで移動 |
| グラフ | S6 | グラフ | 線種と印で区別、表を併設 |
| 状態の表示（入力済み・未入力） | S3、S4 | バッジ | 印と文字を併記 |
| コードの表示とコピー | S1、S2 | 表示とコピーのボタン | 1 度だけ表示と明記 |
| 更新の通知 | S3 | 控えめな更新領域 | |

## 画面の状態の表現

| 状態 | 表現 |
| :--- | :--- |
| 空 | 説明の文章と、次の操作の案内 |
| 読み込み中 | 内容の形をした薄い枠。5 秒を超えたら文章で知らせる |
| 成功 | 近くに短い文章。自動で消すのは 5 秒後 |
| 誤り | 原因のそばに、印と文章 |
| 無効 | 押せない理由を文章で示す |

## 表記のそろえ方

- 同じ操作は、全画面で同じ名前、同じ位置にする（例: 「確定する」は常に右下）
- 役割の名前は、「工場」「一次卸」「二次卸」「小売店」で統一する
- 設定の種類は「キット準拠」と「カスタム」で統一する
- 「発注数」と「生産要請数」を使い分ける。工場の画面だけ「生産要請数」
- 数値の単位を必ず添える。金額は「$」を付け、小数点以下 2 桁で示す
