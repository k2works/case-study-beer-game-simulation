# アクセシビリティの確認表

NFR8（`requirements.md`）と、ストーリー US5.5（`stories.md`）の受入条件を、WCAG 2.2 AA に沿って確認項目にしました。この確認表は、実装の各段階（画面の設計、実装、試験）で使います。仮の値（4.5:1 など）は、NFR 要件の工程で確定します。

## 知覚できること

| 項目 | 確認の内容 | 対象 | 状態 |
| :--- | :--- | :--- | :--- |
| 色のコントラスト | 通常の文字で 4.5:1 以上。大きな文字で 3:1 以上。枠や図形で 3:1 以上 | 全画面 | 設計済み（値は技術スタックで確認） |
| 色だけに頼らない | 状態（入力済み、誤り、一時停止、カスタム）は、印と文字でも示す | S2、S3、S4、S6 | 設計済み |
| グラフの区別 | 系列を線種と印でも区別する。同じ数値の表を併設する | S6 | 設計済み |
| 画像の代替 | グラフに文章の要約を付ける | S6 | 設計済み |
| ページの言語 | 日本語と宣言する | 全画面 | 設計済み |
| 拡大 | 200% に拡大しても、内容が失われず、横にスクロールしない | 全画面 | 実装時に確認 |

## 操作できること

| 項目 | 確認の内容 | 対象 | 状態 |
| :--- | :--- | :--- | :--- |
| キーボードだけで操作 | ゲーム作成から週の確定まで、すべてキーボードだけで完了できる（AC5.5.1） | 全画面 | 試験で確認 |
| フォーカスの順 | 見た目の順（左から右、上から下）に移る | 全画面 | 実装時に確認 |
| フォーカスの枠 | 見える枠（2px 以上、3:1 以上）。消さない | 全画面 | 設計済み |
| キーボードの罠 | ダイアログ以外で、フォーカスが閉じ込められない | 全画面 | 試験で確認 |
| ダイアログ | Escape で閉じる。フォーカスを中に留め、閉じたら呼び出した要素に戻す | S4 | 設計済み |
| 時間制限 | 入力に時間制限を設けない。自動の更新は、読み上げを妨げない | S3、S4 | 設計済み |
| スキップの導線 | 最初に本文へ移るリンクを置く | 全画面 | 実装時に確認 |
| 動き | `prefers-reduced-motion` を尊重する | 全画面 | 実装時に確認 |

## 理解できること

| 項目 | 確認の内容 | 対象 | 状態 |
| :--- | :--- | :--- | :--- |
| ラベル | すべての入力欄に、常に見えるラベルがある | S0、S1、S3、S4 | 設計済み |
| 誤りの説明 | 何が起きたか、なぜか、次に何をするかを文章で示す | 全画面 | 設計済み |
| 一貫した操作 | 同じ操作は、同じ名前、同じ位置 | 全画面 | 設計済み |
| 取り消せない操作 | 確認で、何が起きるかを書く | S4 | 設計済み |
| 入力の保持 | 誤りのとき、入力済みの他の値を残す | S0、S1、S3 | 設計済み |
| 突然の変化 | 入力や選択だけで、画面が勝手に移らない | 全画面 | 設計済み |

## 頑健であること

| 項目 | 確認の内容 | 対象 | 状態 |
| :--- | :--- | :--- | :--- |
| 見出しの階層 | h1 から順に使い、飛ばさない | 全画面 | 実装時に確認 |
| 表の見出し | 行と列の見出しを関連づける | S2、S3、S4、S6 | 設計済み |
| 状態の通知 | 保存、置き換わり、入力済みの数の更新を、控えめな更新領域で知らせる | S3 | 設計済み |
| 現在位置 | 現在のステップを `aria-current` で示す | S3 | 設計済み |
| ネイティブ要素 | ネイティブの要素を優先し、補助の属性は足りないときだけ使う | 全画面 | 実装時に確認 |

## 確認の方法

1. 自動の走査（axe など）。見つけられるのは一部だけ
2. キーボードだけの操作（マウスを使わない）
3. スクリーンリーダー（VoiceOver など）での読み上げ
4. 200% への拡大
5. 色覚の模擬（色だけに頼っていないことの確認）

## 対象のブラウザ

Chrome、Edge、Firefox、Safari の最新 2 世代（NFR10。ブラウザ名は仮の値）。
